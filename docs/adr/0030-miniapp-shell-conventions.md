# Mini App shell: same-origin `/api`, session in memory, browser mode for development

- **API on the same origin.** The Mini App calls `/api/*`. Vite proxies it in development and Caddy in production, stripping the prefix, so the API needs no CORS (the admin already works this way, ADR 0027).
- **The session token lives in memory only.** It is short-lived (ADR 0029) and Telegram hands the app fresh `initData` on every launch, so nothing needs persisting. A per-device hint (language and theme, in `localStorage`) only prevents a wrong first paint; the server is the source of truth.
- **Browser mode.** Outside Telegram the app reads launch params from the URL hash and runs the SDK's mock environment, but only in the dev server or a build with `VITE_BROWSER_MODE=1`. It is no way around authentication: the API still verifies the `initData` signature.
- **Theme.** Tokens are CSS variables in one file (`apps/miniapp/src/styles/tokens.css`), swapped by `html[data-theme]`, wired into Tailwind v4 as semantic roles (`bg-ground`, `text-ink`). Components never use hex values.
- **Bundle budget.** `apps/miniapp/scripts/check-bundle-size.mjs` reads the Vite manifest and fails CI above 150 KB gzip of initial JS.
- **No zod in the Mini App (amended after review).** `@ts-rest/core` imports zod at runtime, and the server contract carries the schemas, so together they cost ~14 KB gzip of initial JS. The Mini App uses `@lummi/contracts/client` instead: a table of each route's method, path and response statuses, typed as `typeof contract` (the server contract, imported as a type only), so bodies and responses keep one source of truth. `ClientMatchesServer` (compile time) and `client.test.ts` (runtime) fail when the table drifts from the server contract. The requests themselves go through a small typed fetch client (`apps/miniapp/src/lib/client.ts`) that imports only ts-rest's types. Initial JS went from 141 to 127.5 KB gzip. Adding a route means adding one line to `clientRoutes`.
- **i18n namespaces.** `@lummi/i18n` exports only language helpers and the shared strings. Each surface imports its own namespace (`@lummi/i18n/miniapp`, `/bot`); `@lummi/i18n/all` merges them for the API. `defineMessages(ru, uz)` keeps the guarantee that a key missing or extra in either language fails typecheck.
- **Browser mode cannot ship.** A production build fails when `VITE_BROWSER_MODE` is set, and `npm run size` (run in CI) fails when `dist` contains `mockTelegramEnv` or the browser-mode marker.
- **No colour in `index.html`.** The first-paint ground colours are injected from `tokens.css` at build time (`html.test.ts` guards it).
