# Tracked campaign links; orders take the last link within N days, customers keep the first

A `startapp` parameter is short and limited to `A-Z a-z 0-9 _ -`, so it carries a key, not data. Plain navigation links (`p_<slug>`, `set_discovery`, `builder`; used by «Поделиться») are not tracked beyond a "share" mark. A **campaign link** (`l_<code>`) is created by the owner in admin and points to a target screen, an optional promo code (which it prefills) and a **source** (Instagram, channel, store QR, a blogger). Every promo code gets one automatically, and admin can download a QR image for store stands. Every open is logged (customer, link, time). "Opens" in reports count unique customers.

Attribution: an **order** takes the last campaign link the customer opened within N days before ordering (setting, default 7), and source reports use that. A **customer** keeps the first campaign link they ever opened, as the acquisition source. The promo report stays as TZ defines it, keyed on the code applied to the order. Its conversion divides fulfilled orders that came through the code's link by that link's opens, and is hidden for codes without a link. A prefilled code that turns out invalid still leaves the source on the order (ADR 0002, spec 2026-11-07 promo counting).
