# Frontend stack: lean React Mini App on brand tokens; Next.js admin that talks only to the API

**Amended 2026-11-18:** the budget is 152 KB gzip. Profile photos (#67) and the promo gift (#69) put the initial load at 150.2 KB, almost all of it RU and UZ strings: both dictionaries ship on every first load. #73 loads only the customer's language, which wins back several KB; then the budget returns to 150. 2 KB is a few milliseconds on 4G, so TZ §2 «первый экран меньше 2 секунд на 4G» still holds.

**Mini App** (`apps/miniapp`): React + Vite + TS. `@telegram-apps/sdk-react` covers initData, viewport, safe areas, theme, back and main buttons, `requestContact` and `requestWriteAccess`. TanStack Router is typed and maps `startapp` to routes; TanStack Query sits over the ts-rest client. Styling is Tailwind CSS v4 on brand tokens (Milk, Stone, Graphite, Sage, radii) as CSS variables. Light is the default theme. Dark mode is built from **our** tokens (Graphite surfaces, Milk text), is switched on by the customer in Profile and saved per customer, and never uses Telegram's palette or `colorScheme`; the app sets Telegram's header and background colours to its active theme. *(Amended 2026-11-07: the customer's design approval made light the default and dark an option; it originally followed Telegram's `colorScheme`.)* Components are our own small set, with Radix primitives where needed (sheet, dialog) and no heavy UI kit. Tenor Sans, Manrope and Cormorant Garamond Italic are self-hosted as Cyrillic + Latin subset `woff2`, and first-screen faces are preloaded. Budget for the < 2 s first screen: initial JS ≤ 150 KB gzip, route-level code splitting, WebP `srcset` with lazy loading, bundle size checked in CI.

**Admin** (`apps/admin`): Next.js App Router, shadcn/ui, TanStack Table, react-hook-form + zod, ts-rest client. It never touches the DB and has no server actions that write: the API is the only DB writer (ADR 0015). Caddy routes `admin.<domain>/api/*` to the API, so the session cookie is same-origin and no CORS is needed.
